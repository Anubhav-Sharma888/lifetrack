# LifeTrack localhost preview

Run `node server.cjs` in this directory and open http://localhost:4173.

This is a browser adaptation of the delivered native Android app, with sample data. It is not the APK running in an emulator. All preview data stays in this browser's localStorage. It does not access the Android Room database and has no external network dependencies.

Explore Today, Analytics and Settings; check in, hold or right-click to skip/add a note, add/edit habits, select past dates, use missed-day freezes, drag cards to reorder, archive/restore/delete, change themes, and export/import JSON. Reset demo restores the sample dataset after confirmation.

Version 1.1 adds search, category/status filters, useful starter templates, keyboard-accessible reorder arrows, numeric goals, weekday schedules with revision history, preserved archive intervals, undo that restores notes/status/progress, and draft recovery. The local calendar refreshes on focus, visibility changes and every 30 seconds. An invalid saved record is retained with an option to download it; it is not silently overwritten with sample data.

Beyond the evaluated 1.1 baseline: status changes are one to two taps — the row menu offers Skip and Mark as missed for any marked day (both undoable and note-preserving), and tapping a status in the check-in sheet saves instantly. When a scheduled day ends without records, the next visit shows a "left unmarked" banner with a deep link that highlights the missed rows; the same link works as a URL parameter (`?date=YYYY-MM-DD&focus=unmarked`). A daily reminder time can be set in Settings; the preview nudges in-app once per day after that time while habits are still open, and the native app delivers it as a real notification. The reminder preference lives in this browser's local storage, is not part of backup files, and is per browser profile.

Version 1.2 adds **activities**: free-form workouts and movements (push-ups, runs, crunches — anything you name) logged on any day in any combination, with no fixed sequence. Quantities are recorded exactly as performed — 32 against a 20 target is a good day, never an overshoot. Targets are optional. Each activity's history, 28-day totals and best day sit alongside habit consistency in Analytics. Activities are included in backups (format version 3; older version 1 and 2 backups import unchanged) and in the native app's Room database (schema version 3).

After a habit has any saved check-in, its target and unit are locked so historical quantities keep their original meaning. Create a new habit to use a different goal; names, colors, reminders and future schedule revisions remain editable. Editing a saved check-in, including through a hold/right-click, starts with its existing status.

Backups use the native version 2 format; valid version 1 backups migrate in memory. Import validates all required fields, dates, timestamps, references, schedule/pause history, numeric progress and monthly freeze usage before replacing data. Optional password protection uses the same AES-256-GCM / PBKDF2-HMAC-SHA256 format as Android. Passwords are never stored; losing the password means the encrypted backup cannot be recovered. Plain backups are readable JSON. Plain data is limited to 10 MB and encrypted envelopes to 15 MB.

Run the standalone Node tests with `npm test` or `node --test tests/*.test.mjs` (Node.js 18+). No packages need installing. The synthetic interoperability fixture was generated by the actual compiled Android `BackupCrypto` implementation; it contains no real credentials or user records.

For evaluation without touching the normal preview's saved records, open **http://localhost:4173/?qa=review**. The `qa` query selects a separate storage/draft namespace. Browser export prepares a download; only the user/browser can confirm whether the file was ultimately retained.

The notification and wallpaper-color toggles demonstrate settings; actual Android notifications and Material You run in the native application. Browser export downloads a file; the Android version uses the Storage Access Framework.
