# LifeTrack 1.6.0 — "The Personal Almanac" design mapping

Visual-only integration of the Google Stitch "Personal Almanac" frames into LifeTrack. Every label, action, route, dialog and behavior of the working app is preserved; where frame text differs, the working app wins (see "Label deltas" per screen). Sources: `almanac-review/stitch_lifetrack_almanac_ui_redesign/{the_personal_almanac/DESIGN.md, today_personal_almanac, activities_ledger_logging, activity_history_chronology, analytics_almanac_chronicle}` (each with `code.html` + `screen.png`); browser `source/Preview/dist/` (index.html, styles.css, analytics.css, app.js, analytics.js); Android `source/app/src/main/java/com/lifetrack/app/ui/`.

Conflict rule used throughout: DESIGN.md is authoritative for tokens/anatomy; the four frame HTML files are authoritative for rendered geometry where they disagree with DESIGN.md (flagged inline).

## 5. Accessibility conflicts in the frames + resolutions

1. **Viewport lock:** frames ship `maximum-scale=1.0, user-scalable=no` — do not copy; keep current zoomable viewport.
2. **Sub-12px text:** `label-caps` 11px and 9–10px captions/stamp sublabels are below comfortable size; floor: browser 11px only for non-essential eyebrow labels, 12px for anything carrying information; Android minimum 12sp. `mono-caption` 11px restricted to decorative stamps.
3. **Contrast:** `--faded #8C8479` ≈3:1 on paper — decorative only; functional timestamps/meta use `--muted` (≥4.5:1). White check on Sage ≈3:1 — acceptable as non-text glyph because `stateDescription`/`aria-label` carry state and glyphs are shape-distinct; keep.
4. **Touch targets:** frame steppers 44px (`h-11`), 36px card buttons (`h-9`), 40px calendar cells — current 48dp minimums win; bump all mapped controls to 48×48 (month cells `min-height:48px`, browser chips keep 44px height + full-width hit area via padding — acceptable as they sit in dense rows, but prefer 48 where space allows).
5. **Hover-only affordances:** frame hover states (border deepen) must pair with `:focus-visible` outline 3px `--ink` (current pattern) and `.drag-handle` reveal on focus (current).
6. **Motion:** frame `animate-pulse`/toasts gated behind `animationsEnabled` + `body.quiet` + `prefers-reduced-motion` (existing). Hard offset shadows replace blurs — no new motion.
7. **Live regions:** keep `#toast[role=status]`, `.form-error[aria-live]`, reset `aria-live=assertive`, Android `liveRegion` usage; day-summary percent change may add `aria-live=polite` (optional). Frames' silent toasts are not to be imitated.
8. **Dialogs:** native `<dialog>`/Compose `Dialog` focus trapping and opener-focus restore (current) supersede frame demo modals; frame sheet-handle is decorative — keep, mark `aria-hidden`.
