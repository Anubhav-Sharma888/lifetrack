# LifeTrack v2.4.0 Preview 1 — Goal Plan Import

Testing prerelease based on Prompt 4 commit `6c15b6d219c1b8651e73afc9dc331f23cc18b638`.

## What's new

- Import a LifeTrack Goal Plan JSON document from Goals using the system document picker.
- Review the goal, phases, milestones, tasks, dependencies and differences before confirming.
- Resolve conflicts with Keep existing, Use imported, Copy as new or Skip.
- UUID identity and ownership checks protect existing records. Copy creates fresh identities.
- One transaction revalidates the reviewed state and applies the plan. Failed imports roll back. Repeated equivalent imports are idempotent.
- Existing completion states, history, habit data and unrelated goals are preserved.
- Room schema 13, full-backup format v12 and Goal Plan schemaVersion 1 continue unchanged.

## Installation and privacy

The APK uses isolated package `com.lifetrack.app.v2p4` and label **LifeTrack 2.4 Preview**, following the previous preview convention. It installs alongside earlier packages. Their data does not appear automatically. Use supported backup export/import to transfer data and keep your original backup.

This is a debug-signed testing APK. Its certificate report and SHA-256 checksum are attached. Signing continuity across future builds of this isolated package is not guaranteed.

The app remains offline with no INTERNET permission and automatic Android backup disabled. Goal Plan JSON is a distinct document type. Select it through **Goals → Import Goal Plan**. Whole-app backups use Restore Backup.
