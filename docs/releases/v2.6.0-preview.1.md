# LifeTrack v2.6.0 Preview 1 — Session Recovery, Analytics and Habit Alarms

Testing prerelease based on Prompt 6 commit `28efbe38a3a4ac102d9fb35ae176d36589720e55`.

- Explicit partial-session reporting, skip, reschedule and bounded snooze; original plans and history preserved.
- Goal session analytics with planned versus actual effort and honest completion rates.
- Multiple ringing alarm times per habit, with daily, selected-weekday and once recurrence, dismiss and snooze.
- Additive Room schema 15 and full-backup format v14. Older supported backups remain importable; v14 alarm backups require a compatible newer app.
- Includes study sessions, reminders and Goal Plan import from preceding prompts.

The APK installs separately as `com.lifetrack.app.v2p6`, labeled LifeTrack 2.6 Preview. Existing data does not transfer automatically. Use supported backup export/import and retain the original backup. This CI debug-signed APK does not promise signing continuity for future builds.

Offline-first with no INTERNET permission and automatic Android backup disabled. App Lock settings stay local. Alarm behavior depends on Android permissions, DND policy and device settings; sound under DND/silent, lock-screen full-screen presentation, exact-alarm revocation and OEM behavior are NOT device-certified. TalkBack, large-font, picker, keyboard and device upgrade QA remain pending.

The implementation report states 669 passing tests across 42 suites, lint with zero errors (30 warnings, 4 hints), and successful debug assembly. Publication requires fresh GitHub Actions full tests, lint, build, package/version inspection, signature and checksum verification. See its workflow run for observed results.
