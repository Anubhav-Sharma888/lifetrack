# LifeTrack v2.3.0 Preview 1 — Goal Progress, Habit Links and AI Goal Plans

**Testing prerelease.** This release builds upon v2.2.0's Goal Roadmaps and the verified Prompt 3 commit. It is not production-certified.

## What's new

- Honest progress summaries for goal and phase tasks and milestones, including a clear "not yet measurable" result for empty plans.
- Task quick actions for Start, Done, Reopen and Restore; user-confirmed completion timestamps are preserved, and reopening clears them.
- Milestone verification and reopening, including visibility into unfinished supporting tasks.
- Distinct prerequisite labels for completed, intentionally bypassed (skipped), and pending dependencies. Skipped is never counted as completed work.
- Supporting habits: link existing habits to goals, unlink, and see read-only 28-day activity signals without modifying habit history or Smart Streaks.
- Additive **Room schema 13** and **full-backup format v12** for habit-goal links.
- Offline versioned **LifeTrack Goal Plan JSON** format and strict bounded parser, validation, exporter and examples, enabling AI-assisted planning.
- Includes all the earlier LifeTrack features, including v2.2.0 Goal Roadmaps and its CI-stability hotfix.

## Important limits

- **AI Goal Plan JSON importing is not supported yet.** Prompt 3 validates and exports plans; Prompt 4 will deliver conflict preview and transactional partial import. The Goal Plan JSON format is **not** a whole-app backup and must not be imported using the existing Restore Backup function.
- Habit links are association-only: habit check-ins do not automatically complete goal tasks or milestones.
- Physical-device QA (including TalkBack, large fonts, DatePicker and complex IME flows) has **not** been completed. This is a testing prerelease.
- Goals do not automatically complete merely because their planned date arrives, or because all tasks are done.
- Full-backup format v12 may not be restorable in older LifeTrack releases.

## Installation, identity, privacy

**Isolated preview package:** `com.lifetrack.app.v2p3` (app label **LifeTrack 2.3 Preview**). This intentionally installs alongside the stable app, the v1.11 preview and the v2.2 preview, without overwriting their private data. Previous installations' data will not automatically appear in this app. Use the app's supported export/import operations, and independently verify a restore before uninstalling anything.

**Debug signing is generated in GitHub CI and is not a guaranteed persistent signing identity.** Future preview APKs may not upgrade this installation in place. Version-specific package IDs deliberately prevent accidental replacements until a persistent signing/upgrade strategy is established.

LifeTrack remains offline-first. Exported plain JSON backup files can include sensitive records; secure them carefully. The app's App Lock configuration is not included in backups.
