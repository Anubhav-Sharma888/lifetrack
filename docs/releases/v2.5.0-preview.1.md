# LifeTrack v2.5.0 Preview 1 — Study Sessions and Reminders

Testing prerelease based on Prompt 5 commit `38cca4e7235dfa7ddbe2c3936d12db63bd965ca2`.

- Plan study sessions with timezone-aware start/end times and optional goal, phase and task links.
- Start, confirm, cancel and review sessions explicitly. Sessions never complete automatically.
- Permission-aware WorkManager reminders and session deep links behind App Lock.
- Additive Room schema 14 and full-backup format v13; older supported backups remain importable.
- Includes Goal Plan import from Prompt 4. Recovery, analytics and ringing habit alarms arrive in v2.6.

The APK installs separately as `com.lifetrack.app.v2p5`, labeled LifeTrack 2.5 Preview. Existing app data does not transfer automatically; use supported backup export/import and retain the original backup. This CI debug-signed APK does not promise signing continuity for future builds.

Offline-first, no INTERNET permission, automatic Android backup disabled. Physical-device reminder delivery, Doze, TalkBack, large fonts, pickers, keyboard and upgrade QA remain pending.

The implementation commit reports 613 passing tests, lint with zero errors and successful assembly. This publication requires its own fresh GitHub Actions full tests, lint, APK build, package/version inspection, signature and checksum verification. See the associated workflow for observed results.
