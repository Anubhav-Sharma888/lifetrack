# LifeTrack v2.2.0 Preview 1 — Goal Roadmaps

**Testing prerelease:** This is the first downloadable APK for the Version 2 roadmap. It combines Prompts 1 and 2. It is not a production-certified release.

## What's new

- New **Goals** destination, with goal cards, filters, archive/unarchive and create/edit flows.
- Goal detail screens with phases, milestones, tasks and a vertical roadmap timeline.
- Task dependencies, blocked and overdue indicators, and calendar-safe ordering.
- Explicit date rescheduling, including previewed dependent-task shifts.
- Historical schedule revisions: distinguish original planned dates from later changes.
- New Room schema **12**, with additive migrations from previously supported schemas.
- Full JSON backup format **v11** for Goal Roadmaps and schedule revisions, with support for previous formats v1–v10.
- Includes the v1.11.0 backup-import fix and all previously released LifeTrack features.

## Verification

ZCode reports **446/446 local automated tests** across 30 suites, no failures or skips, and lint with 0 errors / 27 warnings for Prompt 2. The GitHub release pipeline must independently pass its own tests, lint and APK build before publication. Physical-device testing, including the DatePicker flows, TalkBack and large-font behavior, remains **NOT RUN**.

## Installation and data safety

This APK is an **isolated, debug-signed testing build**, packaged as `com.lifetrack.app.v2p2` and labeled **LifeTrack 2.2 Preview**. It installs alongside the stable LifeTrack app and the v1.11 preview, instead of overwriting either. Data in other installations is not automatically shared.

**The debug signing certificate is generated by CI and is not a verified persistent release signing identity.** Future Version 2 previews may not be installable as in-place updates. Export backups before changing installations. Do not uninstall an existing app or clear its storage without independently verifying that your data can be restored.

Plain JSON backups contain readable habits, reflections and other user information. Keep them private. A v11 backup containing Goal Roadmaps is not backward-compatible with older LifeTrack versions.

## Scope / known limitations

- Goal progress aggregation, habit links and AI-generated Goal Plan JSON are planned for Prompt 3.
- Partial non-destructive Goal Plan import is planned for Prompt 4.
- Study sessions and notifications are planned for Prompt 5.
- Goal analytics and session recovery are planned for Prompt 6.
- A low-severity issue concerning orphaned imported schedule revisions is documented for Prompt 4.
- This build has not been certified on a physical Android device; treat it as testing software.
